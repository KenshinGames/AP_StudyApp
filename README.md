# 応用情報 合格ドリル

応用情報技術者試験（IPA）の対策Webアプリ。科目A（四肢択一80問）は4択ドリルと模試で、科目B（記述式）は要点クイズと要点カードで「記述で問われる要点と答えの型」を身につける。土台は簿記3級版（ビルド不要の素のHTML/CSS/JS、単一ファイル構成に近い学習アプリパターン）。

## 構成

- `index.html` — 本体
- `app.js` — 画面・状態管理・間隔反復・模試タイマー
- `questions.js` — 科目A オリジナル120問（6分野×20問）
- `points.js` — 科目B 要点クイズ60問（6分野×10問）＋要点カードデータ
- `cases.js` — 計算・記述系ケース用（現在は空。科目Bは `points.js` で扱う）
- `config.js` — Muse チャット連携URL（未設定ならボタンは出ない）
- `sw.js` / `manifest.webmanifest` / `icons/icon.svg` — PWA

学習記録は端末内（localStorage キー `apstudy.v1`）に保存され、サーバには送られない。記録の引っ越しコード（書き出し/読み込み）にも対応。

## 試験の前提（2026-10 時点で IPA 公式確認）

- 科目A: 150分・四肢択一80問／科目B: 150分・記述式11問から5問（問1 情報セキュリティ必須＋4問選択）
- 合格は科目A・科目Bとも100点中60点以上。科目Aが60点未満だと科目Bは採点されない
- アプリ内の模試は正答率60%を合格ラインとして判定する
- 本番形式の模擬試験 = 科目A 80問・150分タイマー（6分野から抽出）
- 短縮模試 = 科目A 30問（6分野×5問）、分野別内訳を表示
- 科目Bに模試は作らない（記述式のため）。要点ドリルで代替し、本物の記述演習は過去問で行う前提をUI内にも明記

## 問題について

問題・解説はすべてオリジナル作成で、過去問の転載ではない。科目Aは四肢択一と○×の2形式。科目B要点クイズは「記述で問われる要点」を4択化したもの。
