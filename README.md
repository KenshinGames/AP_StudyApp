# 応用情報 合格ドリル

応用情報技術者試験（IPA）の対策Webアプリ。「ゼロ知識から一発合格」を狙い、学習講座で学んでから問題を解く構成。科目A（四肢択一80問）は学習講座・ドリル・過去問・模試で、科目B（記述式）は要点クイズと要点カードで「記述で問われる要点と答えの型」を身につける。土台は簿記3級版（ビルド不要の素のHTML/CSS/JS、単一ファイル構成に近い学習アプリパターン）。

## 構成

- `index.html` — 本体
- `app.js` — 画面・状態管理・間隔反復・模試タイマー
- `questions.js` — 科目A オリジナル120問（6分野×20問）
- `points.js` — 科目B 要点クイズ60問（6分野×10問）＋要点カードデータ
- `past.js` — 過去問（IPA 公開の令和7年度 春期・秋期 午前問題。収録159問、出典ラベル付き）
- `lessons.js` — 学習講座（6分野×3レッスン＝18レッスン＋確認テスト対応付け）と学び方ガイドの本文
- `cases.js` — 計算・記述系ケース用（現在は空。科目Bは `points.js` で扱う）
- `config.js` — Muse チャット連携URL（未設定ならボタンは出ない）
- `sw.js` / `manifest.webmanifest` / `icons/icon.svg` — PWA（キャッシュ名 `ap-v2`）

学習記録は端末内（localStorage キー `apstudy.v1`）に保存され、サーバには送られない。レッスンの進捗は同じオブジェクトの `lessons` フィールドに保存され、v1 の記録はそのまま引き継がれる。記録の引っ越しコード（書き出し/読み込み）にも対応。

## 学習の流れ

1. 学習講座：レッスンの解説（概念・具体例・公式・表・つまずきポイント）を読んでから確認テスト（60%以上で完了）
2. 分野ドリル：オリジナル120問。間違えた問題は「今日の10問」で間隔反復（1/3/7/14/30日）により自動復習
3. 過去問：年度・分野別演習（過去問も同じ間隔反復の仕組みに統合）
4. 本番形式の模擬試験：オリジナル抽出の80問と、過去問そのままのセット（令和7年度春期は1問除外のため79問、秋期は80問）を選べる

## 試験の前提（2026-10 時点で IPA 公式確認）

- 科目A: 150分・四肢択一80問／科目B: 150分・記述式11問から5問（問1 情報セキュリティ必須＋4問選択）
- 合格は科目A・科目Bとも100点中60点以上。科目Aが60点未満だと科目Bは採点されない（まず科目Aを固めるのが定石）
- アプリ内の模試は正答率60%を合格ラインとして判定する
- 本番形式の模擬試験 = 科目A 80問・150分タイマー
- 短縮模試 = 科目A 30問（6分野×5問）、分野別内訳を表示
- 科目Bに模試は作らない（記述式のため）。要点ドリルで代替し、本物の記述演習は IPA の午後過去問 PDF で行う前提をUI内にも明記

## 問題について

- オリジナル問題（`questions.js` / `points.js`）と全ての解説は自作で、過去問の転載ではない。科目Aは四肢択一と○×の2形式。科目B要点クイズは「記述で問われる要点」を4択化したもの
- 過去問（`past.js`）は IPA が公開している公式問題で、IPA の利用条件に従い、各問題に出典（年度・期・試験区分・時間区分・問番号）を明記している。問題文・選択肢は公式PDFから転記し、正解は IPA の解答例と突き合わせて確定した。転記内容は原典画像との全問再照合で二重チェック済みで、少しでも疑いのある問題は収録しない方針とした
- 元の問題の図・表は、文章で漏れなく表せる場合のみ文章化して収録し、その旨を出典ラベルに併記した（34問）。正確に再現できない問題は収録していない（令和7年度春期 問13：稼働率の関係を示すグラフが選択肢のため）
- 年度の追加は `past.js` に Q(...) を足し、`PAST_SETS` にセットを加えるだけでよい
